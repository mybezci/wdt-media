# wdt-media

`german-word-agent` pipeline'ının Instagram görselleri burada barınır
(`media/<tarih>-<slot>-<dil>-<kanal>.jpg`). Ana repo private olduğu için
`raw.githubusercontent.com` buradan servis edilir.

- Yazan: ana repodaki workflow, SSH deploy key ile.
- 60 günden eski dosyalar `retention.yml` ile otomatik silinir.
- Burada kod/sır yok, sadece görsel.
